# Hospital-Management-System
This is Hospital Management System web application that  allows Admins, Doctors, and Patients to interact with the system based on their roles.

Framework to use:
1) Flask for API
2) VueJS for UI
3) VueJS Advanced with CLI
4) Jinja2 templates if using CDN only for entry point
5) Bootstrap for HTML generation and Styling
6) SQLite for Databases
7) Redis for caching
8) Redis and Celery for batch jobs.


                                            Process of Making

Created the Virtual environment in backend by using the code- "python -m venv myenv"
Activating the virtual environment by using the code- ".\myenv\Scripts\Activate"
Deactivate by using "deactivate"
Installing the flask by using the code- "pip3 install flask"
Installed the flask cors, in order to render out the data to specific link/path, by code- "pip install flask-cors"

Coming to Frontend, using Command Line Interface(CLI), I run-"npm create vue@latest"
Further I ran as recommended in the Terminal--

cd Hospital-project
npm install
npm run dev

Further import flask SQLAlchemy using command-"pip install flask-sqlalchemy"
Further import flask Security using command- "pip install flask-security"
Further install the flask CORS using the command- "pip install flask-cors"
