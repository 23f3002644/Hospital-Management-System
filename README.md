# Hospital-Management-System
This is Hospital Management System web application that  allows Admins, Doctors, and Patients to interact with the system based on their roles.

Framework to use:
1) Flask for API
2) VueJS for UI
3) VueJS Advanced with CLI
4) Jinja2 templates if using CDN only for entry point
5) Bootstrap for HTML generation and Styling
6) SQLite for Databases
7) Redis for caching
8) Redis and Celery for batch jobs.
